| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it privately rather than opening a public issue.

Please include:

* A description of the vulnerability and its potential impact
* Steps to reproduce the issue
* Any relevant proof-of-concept code or screenshots
* Suggested remediation, if available

We will acknowledge receipt of your report within 3 business days and aim to provide a detailed response within 10 business days.

Please do not publicly disclose the vulnerability until we have had an opportunity to investigate and remediate it.
